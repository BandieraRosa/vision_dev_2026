## OVERVIEW

RoboMaster auto-aim vision system. ROS2 Humble workspace (C++14/17 + Python launch files). Pipeline: camera capture -> armor detection (OpenCV + MLP) -> EKF tracking -> trajectory solving -> serial command to gimbal MCU via LibXR.

## STRUCTURE

```
vision_dev/
├── src/
│   ├── rm_auto_aim/           # Core pipeline (3 sub-packages)
│   │   ├── armor_detector/    # CV detection + PnP solving
│   │   ├── armor_tracker/     # EKF tracking + trajectory ballistics
│   │   └── auto_aim_interfaces/  # ROS2 msg definitions
│   ├── rm_serial_driver/      # LibXR-based UART bridge to MCU
│   ├── hik_camera/            # Hikvision industrial camera driver (composable node)
│   ├── rm_vision/             # Launch orchestration + config submodule
│   ├── rm_hand_eye_calibrate/ # Hand-eye calibration tool (service-based)
│   ├── rm_gimbal_description/ # URDF xacro for gimbal TF tree
│   ├── rm_simulator_driver/   # Sim driver stub
│   └── libxr/                 # Embedded framework (vendored, has own AGENTS.md)
├── build/                     # colcon build output (gitignored)
├── install/                   # colcon install output (gitignored)

```

## CONVENTIONS

- **Namespace**: `rm_auto_aim` for detector/tracker nodes
- **Naming**: PascalCase for class methods (`ImageCallback`, `DetectArmors`). Snake_case for member variables with trailing underscore (`tracker_`, `dt_`)
- **C++ standard**: Mixed — detector uses C++14, tracker/serial/calibrate use C++17. Match existing per-package
- **Composable nodes**: Camera + detector run in same container via `rclcpp_components` for zero-copy image transport
- **Clang-format**: Google base, 90 col limit, Allman braces (see `.clang-format`)
- **Documentation**: Chinese-language comments and READMEs throughout
- **Config submodule**: `rm_vision_bringup/config` is a separate git repo. Branch = robot type. `git switch <robot_type>` to change

## ANTI-PATTERNS (THIS PROJECT)

- **DO NOT** free memory in LibXR components — intentionally allocate-once (see `src/libxr/libxr/AGENTS.md`)
- **DO NOT** add EIGEN_NO_IO to public compile definitions — removed explicitly in `src/libxr/CMakeLists.txt`
- **DO NOT** edit files under `src/libxr/libxr/` — vendored submodule with own AGENTS.md
- **DO NOT** edit `build/` or `install/` — generated by colcon
- Config submodule (`rm_vision_bringup/config/`) has `ignore = all` in `.gitmodules` — changes tracked separately

## COMMANDS

```bash
# Build
source /opt/ros/humble/setup.bash
rosdep install --from-paths src --ignore-src -r -y
colcon build --symlink-install

# Run (full system)
source install/setup.bash
ros2 launch rm_vision_bringup vision_bringup.launch.py robot:=<robot_type>

# Run (no hardware / sim)
ros2 launch rm_vision_bringup no_hardware.launch.py

# Run (individual)
ros2 launch hik_camera hik_camera.launch.py
ros2 launch rm_serial_driver ros2_libxr_launch.py
ros2 launch rm_hand_eye_calibrate hand_eye_calibrate.launch.py

# Camera calibration
ros2 run camera_calibration cameracalibrator --size 11x8 --square 0.02 image:=/image_raw camera:=/hik_camera

# Git hooks (first clone)
git config core.hooksPath .githooks
```

## NOTES

- Launch system does `git checkout` on config submodule at startup (`vision_bringup.launch.py` L119-134). Config branch must exist
- Serial driver delays 1.5s, tracker delays 2.0s after camera+detector container starts
- Lob-shot mode switches camera intrinsics and trajectory table at runtime
- `tracker.sh` is a watchdog script — auto-restarts tracker node if it crashes
- Outpost tracking has special noise parameters (`s2qxyz_outpost_`, etc.)
- Git hooks auto-update submodules on checkout/merge
